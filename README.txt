موقع بودرة النجم الإفريقي - نسيم الطبيعة

الموقع مخصص لهذا المنتج فقط، ويستخدم:
- شعار نسيم الطبيعة الذي أرسله صاحب المتجر.
- صورة العبوة الأصلية دون تعديل.
- صورة الملصق الأصلي كما أُرسلت.

التشغيل:
1) فك ضغط الملف.
2) افتح index.html في المتصفح.
3) لتفعيل استقبال الطلبات، افتح script.js واستبدل 213XXXXXXXXX برقم واتساب المتجر بصيغة دولية دون + أو مسافات.
4) أضف السعر وسياسة التوصيل بعد تحديدهما.

الملفات:
index.html / style.css / script.js / assets/
